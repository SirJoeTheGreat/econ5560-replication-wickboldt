# econ5560-replication-wickboldt

This code replicates “Impact of a Local, Coastal Community Based Management Regime When Defining Marine Protected Areas: Empirical Results from a Study in Okinawa, Japan.” by Shah et. al (2019). The paper can be found at https://doi.org/10.1371/journal.pone.0213354. The complete data were obtained directly by emailing the authors. To run the replication, copy the .xlsx file and the .qmd file into the same folder. To obtain the html output, render the .qmd file. Additionally, individual tables can be obtained by running individual code blocks.
The .qmd file is the file used to run the replication.
The .xlsx file is the file containing the data.
The output folder contains the HTML output of the .qmd file.
The logs folder contains the logs from the .qmd file.
The README file contains information regarding the replication.
A full run takes ~20 minutes.

Shah, Payal, Sahan T. M. Dissanayake, Yoko Fujita, and Paulo A. L. D. Nunes. “Impact of a Local, Coastal Community Based Management Regime When Defining Marine Protected Areas: Empirical Results from a Study in Okinawa, Japan.” PLOS ONE 14, no. 3 (2019): e0213354. https://doi.org/10.1371/journal.pone.0213354.
